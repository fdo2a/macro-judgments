# macro-judgments

미국 CPI·고용보고서 발표일마다 **사람과 AI 가 같은 질문에 확률로 답하고, 그 답을 결과가 나오기 전에 공개 기록으로 남긴 뒤, 5거래일 뒤 코드가 채점하는** 원장이다.

목적은 판단을 쌓고 틀린 이유를 남기는 것이다. **엣지(초과 수익)를 주장하지 않는다.** 표본은 사건 유형마다 1년에 12건 안팎이다.

## 질문 (규칙 v1)

> 발표일(t)에 미 재무부 2년물이 하루 동안 움직인 방향이, 그 뒤 재무부 값이 있는 5번째 날(t+5)까지 이어질 확률은?

- 금리: 미 재무부 Daily Par Yield Curve 의 2 Yr(매 거래일 15:30 ET 무렵 호가 기준). 계산은 정수 bp 로 한다.
- 하루 움직임이 0bp 면 「신호 없음」이라 묻지 않는다. 5일 뒤 변화가 0bp 면 「판정 불가」라 채점하지 않는다.
- 채점: Brier 점수 `(p/100 − 결과)²`(낮을수록 좋다). 결과는 지속 1, 반전 0 이다.
- 비교 기준: 항상 지속(100%), 항상 반전(0%), 기후값(2000년부터 같은 정의로 센 과거 지속 비율, `rules/v1-base-rate.json`).
- CPI 와 고용은 따로 센다. 5일 안에 다른 발표나 FOMC 결정이 끼면 「겹침」으로 표시하고, 겹침 포함·제외를 둘 다 낸다.

전체 정의·시각·한계: [`rules/v1.json`](rules/v1.json). 규칙을 바꾸면 v2 로 올리고 판끼리 합산하지 않는다.

## 흐름

1. 발표가 실제로 있었는지(FRED 발표일)와 재무부 그날 값을 확인한 첫 순간이 **질문 시각 Q** 다. 마감 **D = Q + 2시간**.
2. 사람에게 텔레그램으로 질문을 보낸다. 답장(첫 줄 0-100, 둘째 줄부터 근거)은 **받은 글자 그대로** `human/` 에 저장된다.
3. 같은 순간 AI(고정 모델·고정 프롬프트, `rules/v1.json`)가 같은 자료만 보고 답한다. 답은 **봉인**해 지문(`ai/<사건>/commit.json`)만 먼저 올리고, 마감 뒤 원문(`reveal.json`)을 공개한다. 누구나 지문을 다시 계산해 맞춰 볼 수 있다(`rules/seal-vector.json`).
4. t+5 값이 나오면 `outcomes/` 에 결과를 남기고, `scores/summary.json` 이 다시 계산된다.

마감 판정: 사람은 텔레그램 서버가 붙인 메시지 시각, AI 는 봉인 파일을 올린 커밋의 GitHub 서버 시각.

## 파일

| 경로 | 내용 | 누가 쓰나 |
|---|---|---|
| `rules/` | 규칙, 일정표, FOMC 결정일, 기후값, 시험 예제 | 사람(스크립트로 만들고 검토 뒤 커밋) |
| `events/<사건>.json` | 질문 시각·마감·당일 금리·질문 자료, 또는 질문하지 못한 이유 | Worker, 한 번만 |
| `delivery/<사건>.json` | 질문 전달 성공·실패 | Worker, 한 번만 |
| `human/<사건>/*.json` | 사람 답(원문 그대로). 여러 번 보내면 전부 남고, 마감 전 마지막 것을 채점 | Worker, 한 번만 |
| `ai/<사건>/` | `commit.json`(봉인) → `reveal.json`(공개), 또는 `missing.json`(기권 사유) | Worker, 한 번만 |
| `outcomes/<사건>.json` | t+5 결과 | Worker, 한 번만 |
| `scores/summary.json` | 채점 요약(파생물) | GitHub Actions |

Worker 는 파일을 **만들기만** 하고 고치지 않는다. `main` 은 강제 푸시·삭제가 막혀 있다.

## 한계

- 사람은 질문 이후 나온 뉴스·가격을 보지 않고 답하는 것을 원칙으로 하지만, 지켰는지는 검증할 수 없다.
- 「AI 보다 먼저 기록했다」는 시각으로 확인할 수 있어도 「AI 영향을 받지 않았다」는 증명할 수 없다. 그래서 사람 기록 시각, 같은 날 AI 시황 브리프 공개 시각, 정보 기준 시각을 함께 남긴다.
- 일별 종가 기준이라 발표 직후의 순수한 반응이 아니라 발표일 하루 전체의 움직임이다.
- 레포 안의 기록 순서는 GitHub 서버 시각에 기댄다. 저장소 관리자가 이력을 다시 쓰는 경우까지 막는 외부 증명은 아니다.

## 구성

- `worker/` — Cloudflare Worker(Durable Object 알람 15분 간격, 텔레그램 webhook). 시험: `cd worker && npm test`.
- `scripts/` — 규칙 계산(Worker 와 같은 답, `rules/test-vectors.json`), 채점 요약, 기후값, 일정표, FOMC 목록. 시험: `python3 -m pytest scripts/tests`.
